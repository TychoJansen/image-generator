# Reference photos

Put photos here of the people, animals or places that should appear in the images (JPG, PNG or WebP).

- At every start the app copies them into **Foto's** on the Generate tab, **ticked by default**, so they are sent with
  every image unless you untick them. At most 4 photos can be used per image.
- The **file name is the description**: `personX.jpg` becomes "personX". Use names from your
  glossary (Woordenlijst) so their descriptions are sent along too.
- Changed a photo? It is replaced on the next start. Removed it from this folder? It disappears from the app.
- Only this README is committed: the photos themselves stay on your computer (see `.gitignore`).
